# tea

Original audio with its existing ASR transcript and subtitles. Recognition errors are retained.

Existing supplied-passage checkpoints.

<!-- library-files -->
## Files

- [Reading text](passage.txt)
- [Spoken transcript](transcript.txt)
- [Recording](audio.wav)
- [Checkpoints](checkpoints.json)

passage.txt is the original supplied text when present. reference.txt can be a transcript-derived corpus reference; text_status.json records its status. transcript.txt describes recorded speech and can include reading mistakes, adult prompts or ASR errors.
